## Current Intent

PRD 3.0 stabilizes the current MVP source of truth for the game after PRD 2.0, with stronger emphasis on a four-service Dockerized runtime, an Express backend modular monolith, persistent data ownership, runtime match state, and implementation-readable architecture.

PRD 3.0 should preserve normal-person product explanations while separately clarifying developer-facing service ownership and runtime responsibilities.

PRD 3.0's product promise is that the MVP is a fast competitive mental arithmetic duel where pressure, mastery, comeback tension, rivalry, CPU teaching, PvP competition, community ranking, and lively presentation all serve the duel itself.
