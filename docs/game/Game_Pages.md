# 1P

## Page Purpose

The 1P page is the single-player entry point.

It gives the player access to solo onboarding, CPU duels, player progression, and solo-facing stats.

<a href="#top-level-game-entry">Back to Top-Level Game Entry</a>

## Immediate Pages

### <a href="#page-1p-tutorial">Tutorial</a>

Guided onboarding through CPU 1 and CPU 2.

### <a href="#page-1p-duel-cpu">Duel CPU</a>

Choose CPU opponents and progress through unlockable fighters.

### <a href="#page-1p-shop">Shop</a>

Spend coins on name change and CPU unlocks.

### <a href="#page-1p-stats">Stats</a>

View player profile and performance stats.

## CPU 1 - Streak / Revenge Tutorial

### Page Purpose

CPU 1 teaches the first core combat loop: attack power, streak pressure, `SHOCK!`, revenge activation, and revenge payoff.

Immediate tutorial beats:

- guided attack at power 5.
- guided attack at power 30.
- two free attack rounds.
- forced `SHOCK!` demonstration.
- CPU 5-hit streak demonstration.
- player revenge attack demonstration.
- player streak-building task.

<a href="#page-1p-tutorial">Back to 1P Tutorial</a>

---

<a id="page-1p-tutorial-cpu-1-practice"></a>

## CPU 1 - Simplified Practice Fight

### Page Purpose

The CPU 1 practice fight lets the player practice attacks, revenge, and streak-building without DEFEND.

Immediate page behavior:

- DEFEND is unavailable.
- CPU attacks moderately.
- CPU attacks often enough to interrupt and reset the player's streak.
- player must totally defeat CPU 1.
- after clearing CPU 1, player moves to CPU 2 immediately.

<a href="#page-1p-tutorial">Back to 1P Tutorial</a>

---

<a id="page-1p-tutorial-cpu-2"></a>

## CPU 2 - DEFEND Tutorial

### Page Purpose

CPU 2 teaches the DEFEND mechanic.

Immediate tutorial beats:

- CPU DEFEND demonstration.
- repeated CPU DEFEND demonstration.
- player DEFEND demonstration.
- DEFEND cooldown / alternate-turn lesson.
- DEFEND disrupts a visible CPU streak.
- DEFEND turns revenge into advantage.

<a href="#page-1p-tutorial">Back to 1P Tutorial</a>

---

<a id="page-1p-tutorial-cpu-2-practice"></a>

## CPU 2 - DEFEND Practice Fight

### Page Purpose

The CPU 2 practice fight reinforces DEFEND, streak disruption, and revenge-advantage conversion.

Immediate page behavior:

- CPU has a higher chance of dealing streak damage.
- player revenge meter is more likely to activate.
- player can lose.
- player must totally defeat CPU 2.
- after CPU 2 is defeated, the Shop becomes available in 1P.

## CPU Character Select

### Page Purpose

This page lets the player select a Duel CPU opponent.

Immediate page behavior:

- show Maki and Kander as initially available.
- show Fury, Shi-eld, Peasy, and Skore as locked until criteria are met.
- selecting an available CPU opens the CPU Fight page.
- selecting a locked CPU opens the Locked CPU Criteria page.

<a href="#page-1p-duel-cpu">Back to Duel CPU</a>

---

<a id="page-1p-duel-cpu-locked"></a>

## Locked CPU Criteria

### Page Purpose

This page explains why a selected CPU opponent cannot be fought yet.

Immediate page behavior:

- show required prior CPU clear.
- show required coin cost.
- show whether each requirement is met.

Unlock chain:

- Fury: beat Maki and Kander, then pay 500 coins.
- Shi-eld: beat Fury, then pay 1000 coins.
- Peasy: beat Shi-eld, then pay 1500 coins.
- Skore: beat Peasy, then pay 3000 coins.

<a href="#page-1p-duel-cpu-select">Back to CPU Character Select</a>

## Finding A Match

### Page Purpose

This page appears while Quick Match searches for an available room.

Immediate page behavior:

- show `Finding a match...`.
- search public rooms.
- inspect only one room per Quick Match process.
- allocate the earliest available room.
- do not confirm a match until the room slot is allocated.
- allow Back to cancel matchmaking.

Next pages:

- room allocated -> <a href="#page-2p-room-ready">Room Ready Page</a>
- no room available -> <a href="#page-2p-quick-match-no-room">No Available Rooms</a>

## Room Ready Page

### Page Purpose

The room-ready page lets two joined players prepare to start a PvP match.

Immediate page behavior:

- show `Player ___ VS Waiting...` when only one player is present.
- show `Player ___ VS Player ___` when two players are present.
- ready button is visible in the middle.
- ready button is disabled while only one player is present.
- when both players press ready, show a 3-second countdown above the ready button.
- after countdown, load match page.

Nested page:

- <a href="#page-2p-host-options">Host Options</a>

Next pages:

- both players ready and countdown completes -> <a href="#page-2p-match-page">Match Page</a>
- host options -> <a href="#page-2p-host-options">Host Options</a>
- host closes room -> <a href="#page-2p-enter-game-lobby">Enter Game Lobby</a>
- waiting room expires -> <a href="#page-2p-enter-game-lobby">Enter Game Lobby</a>

The match page displays the active fight UI.

- show player health bars.
- show attack status bars.
- show DEFEND button/status space.
- show shared attack power bar.
- show question prompt.

## Quit Overlay

### Page Purpose

The quit overlay freezes the active match and blocks visibility of the current question.

Immediate page behavior:

- PvC message says match stats will be void.
- PvP message says match stats will be void and quit adds to D/C count.
- opponent sees that the other player pressed quit.
- quit presses are logged.
- repeated quit-button abuse in PvP can trigger forced forfeit.

Next pages:

- confirm quit -> <a href="#page-2p-post-match-results">Post-Match Results</a>
- cancel quit -> <a href="#page-2p-match-page">Match Page</a>
- forced forfeit -> <a href="#page-2p-post-match-results">Post-Match Results</a>

<a href="#page-2p-match-page">Back to Match Page</a>

## Replay / Rematch Flow

### Page Purpose

This page handles PvP replay after results.

Immediate page behavior:

- initiator presses Replay.
- both sides show `waiting...`.
- initiator sees a 15-second countdown.
- if the other player presses Replay, show a 3-second countdown before match starts.
- if the timer expires, Replay greys out and cannot be used from that result screen.
- Back returns to the PvP lobby.

Next pages:

- both players accept replay -> <a href="#page-2p-match-page">Match Page</a>
- replay expires -> <a href="#page-2p-post-match-results">Post-Match Results</a>
- Back -> <a href="#page-2p-enter-game-lobby">Enter Game Lobby</a>

## 2P Leaderboard

### Page Purpose

The Leaderboard page shows the PvP leaderboard.

Immediate page behavior:

- show player's own rank at the top.
- show top 20 players by default.
- allow paging by 20 up to rank 100.
- rank by win rate, then accuracy, then current win streak.
- include only eligible PvP players with at least 10 valid PvP matches.
